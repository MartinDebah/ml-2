# Мартин лох ML-2 — глітч-машина (VST3 / AU)

Ставиться на трек як ефект і зриває його звук у такт DAW: повтор із дробом і прискоренням, реверс, перемішування шматків, стоп стрічки, хруст (зниження розрядності й частоти), гейт. Цикл — два такти шістнадцятими.

## Керування
- **Пади** — ручний зрив, спрацює на наступній шістнадцятій.
- **АВТОГЛІТЧ**: перемикачі вмикають типи зривів; **ШАНС** — як часто машина зривається сама; **ДОВЖИНА** — найдовший зрив.
- **ЗАМОК** запам'ятовує останній візерунок і повторює його щокола.
- **ФОРМА ЗРИВУ**: **ДРОБЛЕННЯ** — розмір шматочка повтору, **ПРИСКОРЕННЯ** стискає повтори в дріб, **ВИСОТА** веде їх угору чи вниз.
- **ВИХІД**: **ХРУСТ** — сила ефекту «Хруст», **ГУЧНІСТЬ**.
- Дисплей показує хвилю виходу за два такти, червоним — де спрацювали зриви, з літерою типу.

Коли DAW стоїть, машина йде за власним годинником у темпі проєкту.

## Збірка
GitHub Actions збирає її автоматично (workflow «Build ML-2»). Готові файли — в артефактах `ML2-VST3-Windows`, `ML2-VST3-macOS`, `ML2-AU-macOS`.
